# operonx-project — a guide for coding assistants

The engine that takes a project's requirements to a verified branch: a
living BRD, a board of cards, coding agents with independent review and
real QA, and questions to the owner that park the work and resume it. Read
the core guide first (`../core/README.md`); every example here is tested
against the installed operonx-project.

1. [Projects](01-project.md): a project and a milestone, what the engine
   does with it, the owner's questions, the bounds, and what a coder inside
   a card may and may not do.
