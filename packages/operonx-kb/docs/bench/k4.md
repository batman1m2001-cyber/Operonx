Contextual costs about 3.5× the tree index per page: every chunk is one call carrying its section
window (1 500 tokens at most); OpenAI's prompt cache served 21% of the contextual input on
`vi_public` (chunks of one window share the prefix). A tree query costs ~$0.13 per 1k queries.

## Decision (for now)

**Nothing becomes default-on.** The only measured comparison (`xquad_en`) shows no significant lift
for contextual (p ≥ 0.086 on every metric and mode), and tree search has no verdict yet. Both stay
opt-in (`CollectionSpec(contextual=ContextualSpec(llm=...))`, `CollectionSpec(tree=TreeSpec(llm=...))`,
`search(mode="tree")`), as the PLAN's rule requires without a measured significant lift. The per-type
decisions (short articles, templated business documents, the mixed real corpus) wait for the
resumed run.
