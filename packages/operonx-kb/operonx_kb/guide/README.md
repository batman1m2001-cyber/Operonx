# operonx-kb — a guide for coding assistants

A knowledge base on operonx: files become versioned documents whose every
character has an address (version, span → page, box), indexed for dense,
lexical and hybrid search, and answers cite spans checked against the text
they quote. Read the core guide first (`../core/README.md`); every example
here is tested against the installed operonx-kb.

1. [Knowledge base](01-kb.md): resources, a collection, add and search;
   ingest a folder as a `Job`; search as a step of your own graph; tools
   for an agent; MCP; the command line.
